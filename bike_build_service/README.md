# BIKE LAB — сайт

Статический одностраничный сайт для удалённой сборки, ремонта, апгрейда и диагностики велосипедов.

## Запуск
Откройте `index.html` в браузере.

## Важно про AI
Чат сейчас работает локально на готовых сценариях, поэтому сайт можно открыть без сервера и API-ключа.
Для настоящего AI-бота нужно подключить backend/API (например, OpenAI API) и хранить ключ только на сервере.
